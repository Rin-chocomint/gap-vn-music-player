Penting untuk di ketahui !! :

Fitur ini masih dalam tahap konstruksi dan penelitian!!, Tetapi meski begitu, sebagian besar fitur dasar visual novel sudah bisa kamu coba gunakan.

Literatur :

Aplikasi ini bekerja dengan kode yang tidak terkompilasi untuk transparansi maksimal. Siapa pun bisa mengkostum aplikasi ini langsung ke kodenya, atau membuat novel buatan mereka dengan kode-kode yang pembuat/moder aplikasi atau novel mau. Maka dari itu sangat tidak direkomendasikan kamu mengubah kode program aplikasi ini jika kamu tidak tahu apa yang sedang kamu lakukan.

Entah itu kode yang kreatif tetapi bisa-bisa saja sensitif terhadap sistem atau lain sebagainya. Meskipun aplikasi kami ada scanner keamanan yang suatu saat bisa memberitahu kamu jika ada kode yang berbahaya pada novel buatan orang lain yang sedang kamu mainkan, ini tidak menjamin 100% bisa terdeteksi.

Jadi pastikan kamu mempercayai pembuat novelnya untuk kamu mainkan.

Kalau kamu mau mencari kepastian lebih soal keamanan novel buatan orang lain di komputer kamu namun awam koding/pemrograman, kamu bisa gunakan AI Agent koding (mis. Antigravity, Codex) untuk disuruh melakukan pengecekan menyeluruh terhadap folder novel yang mau kamu mainkan sebelum di-play.

Kustomisasi Novel

Pengaturan Hub

Template Hub

Pilih gaya halaman awal novel. Template menulis ulang hub.html, hub.css, dan markup tiap scene sesuai temanya — semua bisa di-Undo. Setelah diterapkan, bebas kamu sesuaikan lagi per scene lewat Buka Editor Kode atau VS Code. Profil Novel tetap utuh.

Kartu dikelompokkan per keluarga susunan — yang membedakannya adalah letak judul dan menu, bukan sekadar warna. Kartu bertanda aktif = template yang sedang dipakai. Foto pada kartu dipotret dari hasil penerapan yang sebenarnya (npm run thumbnails), memakai metadata & artwork contoh. Template tersimpan di aset/game/hub-templates/<id>/.

Konfigurasi VN Player

Global Default

Template Player — Global

Menerapkan template menulis file milikmu (player.html + theme.css), lalu template menyingkir — tak ada lagi lapisan tersembunyi. Setelah itu lanjutkan di VS Code sesukamu; player.html tetap ikut update engine karena berupa shim.

Code — Global

Sunting berkas kode target ini langsung di sini. player.html = struktur + scene; theme.css = tampilan; extensions/*.js = logika (transisi/efek/command via VNRegistry).

Warna & Tampilan — theme.css

Menyunting file theme.css milikmu — bukan JSON. Ubah lewat picker di bawah atau tulis CSS langsung; keduanya menulis file yang sama, dan file itu bisa kamu buka di VS Code kapan saja.

Perilaku Cerita

Setelan permukaan cerita — bukan tampilan. Keduanya tak bisa ditulis kreator dalam CSS, jadi tetap config dan tidak ikut template. Scene lain (alert, ending credit) tak mengenal keduanya.

Perilaku — chapter aktif

Setelan khusus chapter ini. Pakai switch Ikut Global di header untuk menyalakan/mematikan. Warna & tampilan diatur di fokus Gaya pada tab Code; perbandingan efektif ada di tab Efektif.

Effective Config — chapter aktif

Hasil merge yang benar-benar diterapkan runtime untuk chapter ini: profil Global ditimpa override chapter.
